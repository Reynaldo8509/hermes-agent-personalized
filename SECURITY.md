# Publicación segura

Este repositorio es público. No incluyas tokens de Telegram/LLM, credenciales OAuth, datos personales, volcados, conversaciones, bases de datos ni llaves ADB. Usa variables de entorno o los almacenes de secretos de Hermes y Home Assistant. Si encuentras un secreto, revócalo y rota la credencial; quitarlo de un commit no lo invalida.
